⚡ CHATBOT INTEGRATION — HOW IT WORKS

The chatbot widget auto-injects into any Engine Talk page. Just add these 2 lines to your HTML:

<!-- Add this inside <head> -->
<link rel="stylesheet" href="path/to/chatbot.css">

<!-- Add this before </body> -->
<script src="path/to/chatbot.js"></script>

Make sure your backend server is running on http://localhost:3000 before testing.

👉 Look for the 🚗 floating button at the bottom-right corner of this page!
